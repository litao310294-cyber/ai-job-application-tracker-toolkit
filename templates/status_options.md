## Action Level From Chat Export

| Level | Meaning | Recommended Tracker Update |
|---|---|---|
| P0 | Other side replied and it is not a clear rejection | Set status to `Replied` or `Interview Scheduled`; update reply time and next action |
| P1 | Read but not replied | Set status to `Read No Reply`; plan a polite follow-up |
| P2 | Delivered but unread | Keep waiting; do not follow up too frequently |
| P9 | Clear rejection or low priority | Set status to `Rejected` or low-priority notes |
