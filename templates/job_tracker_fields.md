# Job Tracker Fields

## Applications Sheet

| Field | Purpose | Input Type |
|---|---|---|
| ID | Row number or stable application ID | manual |
| Application Date | Date when the job was applied or recorded | manual |
| Platform | Source platform such as BOSS, referral, official site, or other channel | dropdown |
| Company | Company name | manual |
| Position | Job title | manual |
| City | Job location | manual |
| Company Size | Optional company size range | dropdown |
| Salary Range | Salary or internship allowance range | manual |
| Job Link | Link to the job page | manual |
| Priority Tier | A/B/C/Skip style job priority | dropdown |
| Job Type | Backend, Java, AI application backend, or other type | dropdown |
| JD Keywords | Important keywords extracted from the job description | manual or AI-assisted |
| Match Level | High, Medium, or Low | dropdown |
| Contacted Proactively | Whether the applicant sent an opening message | dropdown |
| Opening Message Version | Which opening message template was used | dropdown |
| Resume Version | Which resume version was used | dropdown |
| Current Status | Current application and communication status | dropdown |
| Read Time | When the message became read, if known | manual or userscript-assisted |
| Reply Time | When the other side replied, if known | manual or userscript-assisted |
| Interview Time | Scheduled or completed interview time | manual |
| Interview Round | First round, second round, HR round, written test, or other | dropdown |
| Interview Result | Not started, passed, pending, failed, canceled | dropdown |
| Blocker or Rejection Reason | Reason for rejection, delay, or mismatch | manual |
| Next Action | Next follow-up action | dropdown |
| Notes | Free-form notes | manual |

## Dashboard Sheet

The dashboard uses formulas to summarize total applications, today applications, read count, reply count, interview count, rejection count, offer count, reply rate, interview rate, and rejection rate.

## Daily Review Sheet

Used for daily job search reflection, including channels used, high-frequency JD keywords, exposed issues, tomorrow's strategy, and preparation focus.

## Interview Review Sheet

Used to record interview questions, project explanation quality, technical weak spots, follow-up status, and review summary.
