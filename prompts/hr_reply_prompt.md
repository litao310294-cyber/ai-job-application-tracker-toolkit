# HR Reply Prompt

You are helping me write polite, concise job-search replies.

## Rules

- Keep the tone professional and natural.
- Do not overpromise.
- Do not pressure the other side.
- Prefer short messages that can be pasted into a recruitment chat.

## Please Generate

1. A reply for immediate response
2. A shorter version
3. A slightly warmer version
4. If appropriate, a follow-up question

## Context

```text
Company:
Position:
What the other side said:
My situation:
Resume direction:
Availability:
```

## Common Follow-Up Template

```text
您好，想再同步一下，我这边对这个方向比较感兴趣，也可以尽快补充简历或项目信息。如果岗位还在招的话，方便帮忙看下是否匹配吗？谢谢。
```
