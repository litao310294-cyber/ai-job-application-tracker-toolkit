# Status Rules

English Summary:
This document defines chat action levels and their mapping to Excel tracker statuses and next actions.

中文摘要：
本文定义聊天行动等级，并说明这些等级如何映射到 Excel 跟进表中的状态和下一步动作。

## Chat Action Levels

| Level | Rule | Recommended Action |
|---|---|---|
| P0 | Other side replied and it is not a clear rejection | Reply soon, send resume, or prepare next step |
| P1 | Message is read but no reply yet | Wait 4-6 hours, then consider a polite follow-up |
| P2 | Message is delivered but unread | Wait first |
| P9 | Clear rejection or low-priority response | Mark as rejected or archive |

## Excel Current Status

- `To Contact`: job recorded but not contacted yet
- `Contacted`: message sent or application submitted
- `Read No Reply`: message has been read but no reply
- `Replied`: other side replied
- `Interview Scheduled`: interview has been arranged
- `Interview Completed`: interview completed
- `Rejected`: not a fit or not moving forward
- `Offer`: offer received
- `Withdrawn`: user chose to stop following up

## Mapping From Chat To Excel

| Chat Level | Excel Status | Next Action |
|---|---|---|
| P0 | Replied / Interview Scheduled | Send Resume / Prepare Interview |
| P1 | Read No Reply | Follow Up |
| P2 | Contacted | Wait for Reply |
| P9 | Rejected | Give Up |
