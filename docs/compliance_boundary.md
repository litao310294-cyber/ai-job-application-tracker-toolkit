# Compliance Boundary

This project is a personal local job-search organization toolkit.

## What It Does

- organizes application status in Excel
- exports visible chat list text from the current browser page into TSV
- provides AI prompts for analysis and follow-up planning
- uses mock examples for public documentation

## What It Does Not Do

- request private platform APIs
- bypass verification checks
- auto-apply to jobs
- auto-send messages
- auto-click recruiter action buttons
- access data that is not visible to the logged-in user
- include real chat records in public examples

## Public Repository Rule

Do not upload:

- real HR names
- real company chat content
- real contact information
- real screenshots
- real exported TSV files
- real Excel tracker files

Only mock data should be committed.
