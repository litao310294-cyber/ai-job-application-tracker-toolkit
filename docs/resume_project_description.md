# Resume Project Description

## Chinese Version

AI 辅助求职跟进工具包：设计并实现面向个人求职流程的本地效率工具，包含 Excel 求职跟进模板、状态统计仪表盘、招聘聊天状态 TSV 导出 userscript、AI 分析提示词与 mock 示例数据。项目支持投递记录、沟通状态整理、优先级判断、每日复盘和面试复盘，强调 local-first、页面可见信息整理和隐私保护。

## English Version

AI Job Application Tracker Toolkit: designed and built a local-first personal job-search follow-up toolkit with an Excel tracker template, dashboard metrics, a Tampermonkey userscript for exporting visible chat status into TSV, reusable AI prompts, and mock examples. The project helps organize application records, communication status, follow-up priority, daily reviews, and interview reviews.

## Short GitHub Description

An AI-assisted local-first toolkit for job application tracking, visible chat status export, Excel follow-up management, and reusable prompts.
